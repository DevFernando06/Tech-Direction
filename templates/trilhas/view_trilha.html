Fundamentos de HTML5 e Estrutura Semântica

Compreenda como organizar o conteúdo da web de forma acessível, compreensível para motores de busca e robusta para leitores de tela e assistentes digitais.

O que é HTML semântico e por que ele importa?

Quando escrevemos código para a internet, não estamos apenas desenhando caixas coloridas na tela de um computador moderno. Estamos gerando uma representação lógica de informação que precisa ser compreendida por pessoas com diferentes capacidades sensoriais, robôs de indexação e dispositivos variados.

HTML semântico consiste no uso intencional de elementos que carregam significado intrínseco sobre seu conteúdo, em vez de depender exclusivamente de elementos genéricos e vazios de contexto como <div> e <span>.

Princípio do Design System: Acesso não é opcional

A estrutura da informação deve ser autossuficiente. Se todo o CSS for desativado, o documento ainda deve ser compreensível, navegável por teclado e perfeitamente anunciado por softwares leitores de tela como NVDA ou VoiceOver.

Principais elementos e seus papéis na página

Cada região da tela possui uma tag nativa específica. Conhecer e aplicar cada uma é a chave para uma experiência consistente:

<header>

Apresenta o cabeçalho introdutório, identidade visual da marca e navegações principais.

<nav>

Agrupa links de navegação com aria-label descritivo para que o usuário possa saltar se desejar.

<main>

O conteúdo central e dominante do documento. Deve existir apenas um elemento principal visível por página.

<article> e <section>

article para composições independentes e distribuíveis; section para divisões temáticas com título.

exemplo-semantico.html 
<!-- Exemplo de documento bem estruturado -->
<header>
    <h1>Tech Direction</h1>
    <nav aria-label="Menu principal">
        <ul>
            <li><a href="/trilhas">Trilhas</a></li>
            <li><a href="/faq">FAQ</a></li>
        </ul>
    </nav>
</header>

<main>
    <article>
        <h2>Fundamentos de HTML5</h2>
        <p>Conteúdo autoral da leitura...</p>
    </article>
</main>

Imagens com alt e ordem lógica de cabeçalhos

Uma imagem sem texto alternativo adequado pode transformar um formulário ou um tutorial em uma barreira intransponível para quem depende de um sintetizador de voz.

Regras essenciais do Tech Direction:

  • Imagens informativas devem ter um texto descritivo claro no atributo alt="...".
  • Imagens puramente decorativas ou redundantes devem possuir aria-hidden="true" ou alt="" vazio.
  • A ordem de cabeçalhos (h1 → h2 → h3) deve ser mantida sem saltos lógicos.
